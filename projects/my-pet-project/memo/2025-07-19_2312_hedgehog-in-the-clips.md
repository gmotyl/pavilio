# Something in the clips is not a bird

**2025-07-19 23:12**

Went through tonight's clips expecting silence and found a solid two minutes of
snuffling and dry-leaf rustling at about 22:40. Not wind. Rhythmic. Pretty sure
it's a hedgehog under the hedge.

Which means the box is a *garden* logger, not a bird logger, and I've been
throwing away half the interesting stuff because the sorter only knows bird
labels and dumps everything else into `unknown`.

Half-formed options:

- Leave it. Project is called Finchwatch for a reason. `unknown` is fine.
- Keep a `mammal?` bucket — no classifier, just don't delete clips the sorter
  fails on during quiet hours. Cheap. Might be enough.
- Actually label the ground stuff. Which means a second label set, which means
  the sorter gets a mode flag, which means an evening I don't have.

Middle option, probably. The clip is the value here, not the label — I just want
to be able to find it again in a month.

Also: this only showed up because I'm recording continuously right now. A level
gate tuned for birdsong will almost certainly gate out snuffling. Note that
before I go and build the gate.
