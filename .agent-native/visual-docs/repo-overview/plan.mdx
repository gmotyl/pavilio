## 1. System Architecture

Source anchors: `ARCHITECTURE.md`, `panel/`

Pavilio is a pnpm monorepo. The `panel` workspace is a Vite + React SPA served by an Express server booted via `tsx server/index.ts` (no watch — server edits need a manual restart).

<Diagram id="arch-overview" caption="Panel workspace: React SPA served by an Express server that fronts the project filesystem, git, agents, and terminals." data={{"html":"<div class=\"diagram-panel\"><div class=\"diagram-card\"><div class=\"diagram-node\">Browser SPA<br/><span class=\"diagram-muted\">src/features/*</span></div></div><div class=\"diagram-card\"><div class=\"diagram-node\">Express server<br/><span class=\"diagram-muted\">server/index.ts · tsx</span></div><div class=\"diagram-box\">Vite middleware (dev)</div></div><div class=\"diagram-card\"><div class=\"diagram-pill\">/api/projects</div><div class=\"diagram-pill\">/api/files</div><div class=\"diagram-pill\">/api/git</div><div class=\"diagram-pill\">/api/agents</div><div class=\"diagram-pill\">/api/terminal</div><div class=\"diagram-pill\">/api/search</div></div><div class=\"diagram-card\"><div class=\"diagram-node\">Project filesystem<br/><span class=\"diagram-muted\">notes · progress · plans · git</span></div></div></div>"}} />

<Callout id="arch-note" tone="info" body="Provider-agnostic by design: each project picks its AI agent in `.agent/config.json`. The panel is the UI; providers (Claude Code, Kilo, Copilot, …) run against the same folder contract." />

## 2. Panel Server

Source anchors: `panel/server/index.ts`

Every request passes a fixed middleware chain before hitting a route. Mobile auth runs before the public health/login endpoints; the main `authMiddleware` gates everything after `/api/auth/*`.

<Mermaid id="server-pipeline" caption="Request pipeline in server/index.ts" source={`flowchart LR
  req([Request]) --> json[express.json]
  json --> mob[mobileAuthMiddleware]
  mob --> pub{public?}
  pub -->|/api/health, /api/auth/login| ok[handler]
  pub -->|otherwise| auth[authMiddleware]
  auth --> routes[/api/* routers]
  routes --> vite[vite.middlewares SPA fallback]`} />

## 4. ProjectView

Source anchors: `panel/src/features/projects/ProjectView.tsx`

The live main view. It renders a tab bar (`ProjectTabsBar`), a search bar, a repo/commits block, an embedded terminals surface, and per-tab panels (Context, Plans, Files, FileViewer). `pages/` is dead — edits belong here.

## 5. Terminal

Source anchors: `panel/src/features/terminal`

Embedded terminals surface mounted inside ProjectView; sessions are pty-backed over the `/api/terminal` websocket. One terminal handle per session is tracked in `terminalHandlesRef`.

<Callout id="terminal-note" tone="info" body="Terminals are long-lived per project tab; scroll and session state are preserved across tab switches (see useTabScrollMemory)." />
